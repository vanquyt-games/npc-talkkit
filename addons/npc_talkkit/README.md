# NPC TalkKit

Dialogue for the NPCs you already have. Add an `NPCTalkKit` node to a character,
write its lines in the TalkKit tab, and call `play()`.

- Documentation: https://talkkit.vanquyt.com
- Source and issues: https://github.com/vanquyt-games/npc-talkkit
- Licence: MIT, see `LICENSE` in this folder.
