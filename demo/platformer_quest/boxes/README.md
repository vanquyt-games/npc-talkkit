# Gallery boxes

The ten dialogue boxes from the [box gallery](https://talkkit.vanquyt.com/guide/box-gallery),
one per traveller in the quest. They are the same boxes as the downloads, moved
from `res://talkkit_presets/` to this folder. One change: `arcade.tres` uses
`arcade/press_start_2p.res`, a copy of its pixel font with antialiasing turned
off, so it stays sharp in projects that drop `.import` files.

The boxes are free to use in any project. The fonts are under the SIL Open Font
License; each folder has the licence text (`OFL-*.txt`).
